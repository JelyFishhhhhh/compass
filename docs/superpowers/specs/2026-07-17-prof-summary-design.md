# 台灣國立大學資訊領域教授查詢網站 — 設計文件

日期：2026-07-17
狀態：已核准（使用者選定方案 B：React）

## 目的

整理台灣所有國立大學資訊相關系所（資工所、資訊相關偏所、資管所、電機所資訊相關組）的教授資料，
製作成可查詢的網頁，供使用者本人推甄選校選教授使用，並可公開分享給他人查詢。

## 範圍

- **學校**：所有國立大學（含國立科大），分批收集：
  1. 第 1 批：台大、清大、陽明交大、成大（四大）
  2. 第 2 批：中央、中山、中興、中正、台科大、北科大（四中＋台科北科）
  3. 第 3 批以後：政大、台師大、海大、暨南、東華、高雄大學、雲科大、高科大等其餘國立大學
- **系所**（`deptType` 四類）：
  - `資工`：資訊工程學系／研究所
  - `偏所`：資訊學院底下偏所（資安所、網媒所、資科所、智慧計算等）
  - `資管`：資訊管理研究所
  - `電機`：電機所中資訊相關組（計算機、多媒體、通訊網路等）

## 架構

Vite + React 單頁應用，無後端。資料為靜態 JSON，build 時直接打包進 bundle
（`import.meta.glob`）。`vite build` 產出可部署至 GitHub Pages。

除 react / vite 外不引入其他相依套件；樣式用純 CSS。

## 資料格式

`src/data/<school-id>.json`，一校一檔：

```json
{
  "school": "台大",
  "schoolFull": "國立臺灣大學",
  "professors": [
    {
      "name": "林OO",
      "title": "教授",
      "dept": "資訊工程學系",
      "deptType": "資工",
      "areas": ["機器學習", "資訊安全"],
      "lab": "OO實驗室",
      "website": "https://...",
      "email": "...",
      "highlights": "近年研究方向 1-3 行摘要",
      "notes": ""
    }
  ]
}
```

- `title`：教授／副教授／助理教授（不含兼任、名譽、退休）
- `areas`：研究領域標籤，取自系所頁或個人頁
- `highlights`：從教授個人頁摘 1-3 行近年研究方向；不逐篇爬論文資料庫
- `notes`：使用者個人筆記，可留空；資料在 repo 內，公開與否由使用者控制
- 查無的欄位留空字串／空陣列，不臆測

## 網頁功能

- 關鍵字搜尋：比對姓名、實驗室、研究領域、亮點、系所
- 篩選器：學校（多選）、系所類型（四類多選）、研究領域標籤
- 結果列表：卡片顯示全部欄位，個人網頁與 Email 為連結
- 顯示目前篩選結果數／總數

## 資料收集流程

由 Claude 以瀏覽器逐校訪問各系所師資頁面，整理為 JSON，分批進行；
每批完成後使用者可抽查修正。來源以系所官方師資頁為主，個人頁為輔。

## 驗證

`scripts/validate.mjs`：檢查所有 JSON 欄位齊全、`deptType` 合法、
email/website 格式，於收集每批資料後執行。
