# COMPASS

**Comprehensive Professor and School Search System** — 台灣國立大學資訊領域教授查詢。

推甄用：整理國立大學資工所、資訊相關偏所、資管所、電機所（資訊相關組）教授資料的查詢網站。純靜態 Vite + React，資料以 JSON 隨站打包，無後端。

線上站台：<https://compass.w1nter.cc>　協作方式見 [CONTRIBUTING.md](CONTRIBUTING.md)。

> **專案狀態：資料收錄完成，推甄季結束後封存**
> 116 學年度（2027 年入學）的推甄資料已於 2026-10-06 收錄完成，31 校全數到齊。
> 推甄季進行中（最晚放榜 2026-12-16）仍受理資料錯誤回報與修正，季末後封存為唯讀。
> 報名前請務必以各校官方簡章為準 —— 每一筆時程下方都附有官方簡章連結。
> 要接手下一屆（117 學年度）請見下方「接手指南」。

## 開發

    npm install
    npm run dev        # 開發伺服器
    npm test           # 篩選邏輯測試
    npm run validate   # 資料格式驗證
    npm run build      # 產出 dist/

## 更新資料

編輯 `src/data/<school>.json`（一校一檔），欄位格式見
[設計文件](docs/superpowers/specs/2026-07-17-prof-summary-design.md)，改完跑 `npm run validate`。
個人筆記寫在教授的 `notes` 欄位；實驗室網頁可加選填欄位 `labWebsite`（http(s) 連結，
有值時實驗室名稱會變成連結）。

## 接手指南（下一屆）

1. 把 `src/schedule.js` 的 `TARGET_YEAR` 改成下一屆民國年（例如 `'117'`）。
   改完之後，所有仍是舊年度的學校會自動在清單上出現「參考往年」標籤，
   月曆會跳過沒有事件的空月份，排序也會把舊年度的學校壓到最後 —— 不需要改程式。
2. 各校簡章約在 9 月中到 10 月上旬陸續公告，`src/data/schedule/<school>.json` 的
   `source` 欄位就是上一屆的官方簡章連結，多數學校把網址裡的年份加一就能找到新版。
3. 新年度資料寫入後，**把該校的舊年度 rounds 整個刪掉**（本專案不保留歷史年度）。
4. 改完跑 `npm run validate`：它會檢查日期格式、`depts[].dept` 是否真的存在於該校
   教授資料（拼錯會直接擋下來）、以及標籤體系的完整性。

**資料紀律（請務必延續）**：每一個日期、金額、資格、名額都必須來自實際抓取到的官方
簡章內文，不得用記憶或推測，也不得抄搜尋引擎的摘要片段。抓不到就留空字串，
不要猜 —— 報名費或資格寫錯會害人做錯決定。某系所若本來就不辦面試，`interview` 留空
但要在 `note` 寫明「僅資料審查，無面試」，才不會看起來像資料缺漏。

**遇到解不出文字的 PDF**：部分學校（如清大）的簡章用 Type 3 字型且無 ToUnicode，
`pdftotext` 只會輸出亂碼。改用 `pdftoppm -r 130 -png` 渲染成圖片後直接閱讀；頁數多時
可先把各頁上緣裁切拼成長圖，快速定位系所所在頁碼。

## 部署

線上站台 <https://compass.w1nter.cc> 由 **Cloudflare Pages** 從 `master` 自動建置部署
（build command `npm run build`，輸出目錄 `dist/`）。`vite.config.js` 已設 `base: './'`，
純靜態、無後端，換到任何靜態主機（GitHub Pages、Netlify…）都能直接用。
